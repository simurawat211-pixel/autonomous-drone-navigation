🔄 HOW IT WORKS:
═════════════════════════════════════════════════════════════════════════════

Step 1: User provides A* weight parameter (1.0-10.0)

Step 2: A* algorithm with self-learning heuristic:
        • Measures distance to goal
        • Detects nearby obstacles
        • Applies repulsion penalty
        • Returns safe, efficient path

Step 3: RL agent learns (optional):
        • Observes grid, drone position, goal
        • Predicts optimal weight
        • Gets reward based on path quality
        • Improves over 100,000+ timesteps

Step 4: Web UI visualizes result:
        • Animates drone movement
        • Shows statistics
        • Allows real-time parameter adjustment

💡 KEY CONCEPTS EXPLAINED:
═════════════════════════════════════════════════════════════════════════════

Self-Learning Heuristic:
  The A* heuristic is "self-learning" because it:
  - Analyzes the local environment (nearby obstacles)
  - Automatically applies higher penalties near obstacles
  - Adapts its behavior based on what it sees
  - Results in paths that naturally avoid dangerous areas

Weighted A*:
  - Weight = 1.0: Optimal (slow)
  - Weight = 2.0: Balanced (default)
  - Weight = 10.0: Fast but suboptimal
  PPO learns to choose the best weight for each situation!

Gymnasium Environment:
  - Standard RL interface
  - Observation: grid, drone position, goal
  - Action: A* weight parameter
  - Reward: path length + obstacle proximity
